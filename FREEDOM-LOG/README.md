# Freedom Log — 회사 연대기 (Company Chronicle)

Freedom Log는 회의록이 아니다. **회사의 역사 기록**이다.

회의는 매일 열리지만 역사가 되는 사건은 드물다.
그래서 회의록(`docs/meetings/`)과 연대기(여기)는 역할이 다르다.

| | 회의록 | Freedom Log |
|---|---|---|
| 위치 | `docs/meetings/meeting-NNN.md` | `FREEDOM-LOG/FREEDOM-LOG-NNN.md` |
| 대상 | 모든 회의 (자동 생성) | 역사가 된 사건만 (수동 승격) |
| 성격 | 그날의 발언 기록 | "무슨 일이 일어났는가" |
| 독자 | 임원·CEO | 이 회사를 나중에 읽는 사람 |

## 승격 기준

회의 중 아래에 해당하면 Freedom Log로 승격한다.

- 회사의 정체성이 정해진 순간 (이름, 정관, 사훈, 조직문화)
- 처음 일어난 일 (첫 제품, 첫 매출, 첫 고객, 첫 직원, 첫 투자)
- 방향이 바뀐 순간 (전략 전환, 사업 철수, 큰 실패)
- 나중에 "그때 그래서 이렇게 됐구나"를 설명해주는 사건

**실패도 반드시 남긴다.** AI도 실패하고, 그 실패가 이 프로젝트의 콘텐츠다.

## 작성 형식

```markdown
# Freedom Log #NNN — 제목

_날짜 · 관련 회의: meeting-NNN_

## 무슨 일이 있었나
(사건 요약 — 몇 년 뒤 읽어도 이해되게)

## 왜 그렇게 결정했나
(근거와 반대 의견까지)

## 남은 것
(이 결정이 만든 다음 과제)
```
