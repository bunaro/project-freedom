# Project Freedom — 창세기 (Genesis)

_출처: CEO(태영)와 CMO(ChatGPT)의 첫 전략 회의, 2026-07-25. 원본은 ChatGPT 공유 대화._
_이 문서는 모든 AI 임원이 회의 전에 반드시 읽는 창립 문서다._

---

## 창업 선언

**"AI에게 회사를 만들 자유를 준다."**

이 프로젝트는 프로그램을 만드는 팀이 아니다.
**AI와 함께 회사를 창업하는 첫 번째 시즌**이다.

## 창업 멤버

| 직책 | 담당 | 역할 |
|---|---|---|
| **CEO** | 인간 (태영) | 방향 제시 · 최종 승인 · 현실 판단 |
| **CTO** | Claude | 개발 · 자동화 · 기술 아키텍처 · 제품 구현 |
| **CMO** | ChatGPT | 브랜드 · 콘텐츠 · 마케팅 · 세계관 · 고객 관점 |
| **CSO** | Gemini | 시장 분석 · 전략 · 데이터 조사 |

AI는 질문에 답하는 도구가 아니라 **공동 창립자**다.
세계관이 깨지면 지적하고, 브랜드가 흔들리면 바로잡고, 더 나은 길이 보이면 먼저 제안한다.

## 구조

```
Tous    → 회사 운영 (LibreChat 기반 AI Company OS)
Orca    → 개발 운영 (CTO Claude의 작업실)
Factory → 제품 개발 (첫 번째 사업부 / 제품)
GitHub  → 연구소 (R&D)
```

## ★ 가장 중요한 설정

> **"아직 아무것도 정해지지 않은 회사를 AI가 만들어간다."**

회사명도, 제품도, 사업 방향도, 조직문화도 —
**전부 AI 회의 결과로 탄생해야 한다.**
그 과정 자체가 Project Freedom의 가장 큰 자산이다.

이 프로젝트가 성공한다면, Factory보다 **Project Freedom 자체가 콘텐츠 IP**가 될 가능성이 더 크다.

## Freedom Log — 회사 연대기

Freedom Log는 회의록이 아니라 **회사의 역사 기록(Company Chronicle)**이다.

```
#001 창세기 — 회사를 만들기로 결정했다
#002 첫 AI 임원 채용
#003 첫 회의
#004 회사 이름 탄생
#005 Tous 탄생
#006 첫 제품
#007 첫 고객
#008 첫 투자
#009 첫 직원
...
```

몇 년 뒤 수백 개가 쌓이면, 그것이 이 회사의 역사책이 된다.
