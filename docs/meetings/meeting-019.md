## 안건

회사명을 오늘 최종 확정한다. 후보는 둘이다 — celuno(셀루노), bunaro(버나로). CEO가 직접 고른 둘이며, 새 후보를 내는 것은 금지한다.

【이번에 새로 확인된 사실 — 판단 기준이 바뀌었다】
(1) CMO와 기술고문이 조어 80개를 냈고 CTO가 다섯 곳(도메인·GitHub·npm·PyPI·Docker)을 전수 검증했다. 결과: .com이 비어 있는 후보가 **80개 중 0개**였다. 발음 가능한 5~6글자 조합은 도메인 투자자가 이미 전부 선점했다. 즉 .com을 필수 조건으로 두면 어떤 새 이름도 통과할 수 없다. 이 조건은 폐기해야 한다.
(2) celuno와 bunaro는 .ai/.io/.co + GitHub + npm + PyPI + Docker Hub **일곱 곳 전부 비어 있다**. 한 이름으로 모든 채널을 통일할 수 있다.
(3) 반면 확정했던 Kaelun은 GitHub와 Docker Hub 두 곳이 막혀 kaelunhq로 우회해야 한다 — 회의 #017이 BigSoulCompany를 탈락시킨 바로 그 조건(회사명과 기술 네임스페이스 분리)에 해당한다.

【결정할 것】
(1) 두 이름에 각각 **의미를 부여하라.** 지금은 뜻 없는 조어지만, 실제 브랜드는 나중에 서사를 붙인다. celuno와 bunaro 각각에 대해 이 회사의 정체성과 연결되는 해석을 만들어라. 억지 어원 갖다붙이기가 아니라, 사람들이 듣고 '아 그렇구나' 할 만한 이야기여야 한다. 어느 쪽이 더 그럴듯한 서사를 만들어내는지가 판단 재료가 된다.
(2) 발음·기억·인상을 비교하라. 한국어 표기(셀루노/버나로)와 영문 표기 둘 다 따져라. 개발자가 터미널에 치기 편한지, 고객이 한 번 듣고 기억하는지, 검색했을 때 우리만 나오는지.
(3) 둘 중 하나를 표결로 확정하라. 둘 다 부적합하다고 판단되면 Kaelun 유지가 대안이지만, 그 경우 우회 두 곳을 감수하는 이유를 명확히 대라.
