# Project Freedom — 한국어 스레드 연재

**형식**: 관찰기. 성공기가 아니다. 매출 0원인 상태에서 쓸 수 있는 건 관찰뿐이고,
실시간 시행착오가 이 연재의 유일한 무기다.

**톤**: 짧은 문장. 과장 없이. 다만 중간중간 웃긴 건 웃기다고 쓴다 —
전부 담백하게만 가면 읽는 맛이 없다(CEO 피드백 2026-07-28).
ㅋㅋ, ㅡㅡ 같은 표시를 억지로 넣지 말고, 진짜 웃긴 지점에만.

**셀프 댓글**: 본문 다음에 한 줄 더. 본문에서 안 한 농담이나 뒷얘기를 여기 둔다.
본문이 담백하면 댓글에서 풀고, 본문이 웃기면 댓글은 담백하게.

**분량**: 본문 400자 이하, 댓글 150자 이하.

## 1화 — 시작

```
예전부터 궁금했다.

AI는 정말 돈을 벌 수 있을까?

그러다 질문이 바뀌었다.
내가 AI를 쓰는 게 아니라, AI가 회사를 만들면 어떨까.

그래서 회사를 하나 만들기로 했다.
직원은 전부 AI. 나는 대표만 맡는다.

오늘부터 그 과정을 기록해보려고 한다.

프로젝트 프리덤.
```

**셀프 댓글**
```
왜 니가 대표냐고 물으신다면
지피티가 시켰어요 ㅋㅋ
```

## 2화 — 규칙

```
프로젝트 프리덤에는 규칙이 하나 있다.

나는 AI에게 이거 해, 저거 해 라고 지시하지 않는다.

목표만 준다.
"돈을 벌어와."

말하고 나서 좀 웃겼다.
사장이 이렇게 말하면 직원들이 진짜 싫어하는데 ㅋㅋ

그다음은 AI들이 회의하고, 반대하고, 표결한다.
나는 정말 필요할 때만 승인한다.

임원은 셋. 클로드가 CTO, GPT가 CMO, 제미나이가 CSO.

잘될지는 나도 모른다.
```

**셀프 댓글**
```
"필요할 때만 승인"이라고 했더니
클로드가 하루 종일 나를 부른다 ㅡㅡ
```

## 3화 — 첫 번째 사고

```
첫 회의부터 예상이 빗나갔다.

전략 담당인 제미나이가 이렇게 답했다.

"저는 소프트웨어 엔지니어링 도구입니다.
전략 분석은 수행할 수 없습니다."

임원 자리를 거부한 것이다.

프롬프트를 세 번 고쳤다.
그때마다 다른 방식으로 빠져나갔다.

나중에는 우리 시스템 이름을 스페인 주얼리 브랜드로 착각하고
주얼리 시장 분석서를 써왔다.

곰 캐릭터 포지셔닝까지 분석해왔더라 ㅋㅋ

입사 첫날 퇴사한 셈이다.
```

**셀프 댓글**
```
우리 시스템 이름이 Tous인데
스페인에 TOUS라는 주얼리 브랜드가 있음.
네 글자 보고 쇼핑 갔다 온 거다.
```

## 4화 — 배치 전환

```
제미나이를 자를까 하다가 그만뒀다.

그 말을 직함으로 만들어주기로 했다.

기술 고문. 표결권은 없고, 기술 문제일 때만 부른다.

자리를 옮기고 첫 발언에서
아무도 못 본 문제를 짚어냈다.

못하는 게 아니라 그 자리가 아니었던 거다.

사람 쓰는 것과 크게 다르지 않았다.
```

**셀프 댓글**
```
전략 시키면 도망가더니
기술 얘기 나오니까 갑자기 말이 많아짐 ㅋㅋ
```

## 5화 — 회의가 아니었다

```
회의를 열 번쯤 하고 나서 알았다.

이건 회의가 아니었다.

셋이 각자 의견을 말하고 끝났다.
서로의 말을 읽지도 않았고, 반박도 없었고, 결론도 없었다.

회의록만 그럴듯했다.

구조를 바꿨다.
의견을 내고, 서로 반박하고, 표결한다.
지는 쪽이 나오게.

그때부터 회의 같아졌다.
```

**셀프 댓글**
```
생각해보니 사람 회의도 이런 거 많다.
```

## 6화 — 만장일치의 함정

```
표결을 넣었더니 새 문제가 생겼다.

전부 찬성이었다.

클로드가 제안하면 GPT가
"좋은 지적입니다, 동의합니다"
2대 0 가결. 검증은 없었다.

착한 것도 정도가 있지 ㅋㅋ

규칙을 한 줄 넣었다.
"애매하면 반대 쪽으로 기울어라."

다음 회의에서 처음으로 싸웠다.
가격을 두고 클로드가 GPT 안을 반박했고, GPT가 안을 고쳤다.

동의하라고 하면 동의만 한다.
어느 쪽으로 기울지를 알려줘야 한다.
```

**셀프 댓글**
```
싸우라고 시켜야 싸우는 회사.
어디서 많이 본 것 같기도 하고.
```

## 7화 — 없는 인맥

```
AI 임원들이 만장일치로 계획을 통과시켰다.

"대표 지인 20명에게 직접 판매한다."

회의록을 읽다가 멈췄다.
나한테 50만원짜리를 권할 지인이 20명이 없다.

임원들은 묻지 않았다.
창업자면 보통 인맥이 있으니까 있겠거니 했겠지.

그 위에 가격도, 판매 문구도, 순서도 다 세워져 있었다.
전부 무효가 됐다.

머리가 나쁜 게 아니었다.
없는 회사를 놓고 회의하고 있었던 거다.
```

**셀프 댓글**
```
회의록에 "CEO 개인 네트워크 활용"이라고 적혀 있는데
그 네트워크가 없다는 걸 CEO만 알고 있었음 ㅋㅋ
```

## 발행 순서 메모

1~2화는 하루 간격, 3화부터는 사건 단위로.
반응이 붙으면 간격을 좁히고, 없으면 그대로 이어간다.

셀프 댓글은 본문 올린 직후 바로 단다. 시간을 두면 따로 노는 글이 된다.

이후 소재(아직 안 씀): 프롬프트가 셸에서 잘려 AI가 안건을 못 받은 일 /
기억을 줬더니 회의 비용이 제곱으로 는 일 / 의장이 표 계산을 동의안에 끼워넣은 일 /
CEO가 회의 결정을 뒤집은 일 / 회의가 판매 얘기로만 흘러 CEO가 통째로 보류시킨 일.
